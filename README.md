# VoiceFlow

VoiceFlow is a voice-first application developed for the DataForge Hackathon.

## Project Structure

- `frontend/` – Web interface
- `backend/` – Python backend and API
- `data/` – Project data
- `tests/` – Tests

## Tech Stack

- HTML, CSS, JavaScript
- Python
- FastAPI
- Rime TTS
